# Define outcomes

> [!WARNING] Status: **Not ready in v1.** OMA has no outcome rubric, grader, evaluation events, deliverable retrieval, or outcome status API.

## Current alternative

Use session events, tool results, output files, and your own application-level evaluation to assess a completed run. These are execution records, not a managed outcome system.

## Compatibility note

Do not send outcome-definition events or expect outcome-evaluation spans. OMA deliberately does not advertise those event types until it can process them with a defensible public contract.
