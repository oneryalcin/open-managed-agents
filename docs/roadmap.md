# Roadmap

This file used to track the original MVP build cycles. Those cycles are long
finished and the tracker had gone stale (it still claimed the engine and
sandbox were "not started" months after they shipped) — exactly the
dishonesty its own header warned against. It now points at the live documents:

- **Product direction and sequencing**:
  [0114 Appliance Product Roadmap](plans/0114-appliance-product-roadmap.md) —
  packaging, admin dashboard, observability, usage metering, and the
  egress→skills→MCP capability track.
- **Release sequencing to external testers**:
  [0145 Road to external testers](plans/0145-road-to-external-testers.md) —
  M1 0.2.0 trust release, M2 0.3.0 capability release, M3 hardening, and the
  tester gate.
- **Runtime rollout gates**:
  [0112 Pi Runtime Rollout Policy](plans/0112-pi-runtime-rollout-policy.md) —
  what each deployment tier requires.
- **Current implementation status**: the "Current Status" section of the
  [README](../README.md), and per-slice plan documents in
  [docs/plans/](plans/) (indexed in [docs/index.md](index.md)).

The historical cycle-by-cycle plan lives in this file's git history
(pre-2026-07 versions).
